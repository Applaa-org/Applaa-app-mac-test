```sql

  id SERIAL PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  completed BOOLEAN DEFAULT FALSE,
  priority VARCHAR(20) DEFAULT 'medium',
  due_date TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 🐛 Troubleshooting

**If migrations fail:**
```bash
# Make sure Postgres is running
psql -d applaa -c "SELECT 1"

# Make sure schema exists
psql -d applaa -c "CREATE SCHEMA IF NOT EXISTS app_test_12345;"

# Run migrations manually
npm run migrate
```

**If API server fails:**
```bash
# Check if port 3001 is available
lsof -i :3001

# Check .env.local has DATABASE_URL (should be auto-created)
cat .env.local
```

**If frontend can't connect:**
- Make sure API server is running on port 3001
- Check browser console for errors
- Verify CORS is enabled (should be automatic)
