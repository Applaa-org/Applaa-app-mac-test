Bedrock Assets Pack (500 mcfunction builds)

How to use:
1) Put these .mcfunction files into your behavior pack at:
   behavior_packs/<YourPack>/functions/
2) In-game, run:
   /function <filename_without_extension>
   Example: /function 001_watchtower_1

Tip (3D preview): Run the function in a flat creative world, then fly around.
You can also save the build with a Structure Block after running it.
