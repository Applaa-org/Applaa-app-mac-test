## How It Works

### When Creating a New App:

1. **User creates app** in Applaa UI
2. **Electron calls backend** (`src/ipc/handlers/app_handlers.ts:885`)
   ```typescript
   const backendResult = await backendAPI.createApp(params.name, appType);
   ```
3. **Backend provisions database** (`backend/src/routes/apps.ts`)
   - Creates unique schema: `app_{id}_{sanitized_name}`
   - Runs base migrations (creates `users`, `app_data`, `schema_migrations`)
   - Returns connection string
4. **Electron writes `.env.local`** (`src/ipc/handlers/app_handlers.ts:1010-1035`)
   - Saves `DATABASE_URL` and `POSTGRES_SCHEMA`
5. **AI detects Postgres** on next chat
   - Reads `.env.local` file
   - Injects Postgres system prompt
   - AI can now create tables and perform CRUD operations

## Troubleshooting

### Issue: Backend Not Running

**Symptoms**: Apps created without `DATABASE_URL` in `.env.local`

**Solution**:
```bash
cd /Users/macbook/Applaa-updated/backend
npm run dev
```

**Verify**:
```bash
curl http://localhost:3000/health
# Should return: {"status":"ok","timestamp":"..."}
```

### Issue: AI Not Detecting Postgres

**Symptoms**: AI suggests Supabase instead of Postgres

**Check**:
1. Verify `.env.local` exists in app directory
2. Verify `DATABASE_URL=` is in the file
3. Check logs in Electron console for detection messages

**Solution**: Create a new app (old apps might not have `.env.local`)

### Issue: Connection Errors

**Symptoms**: `ECONNREFUSED` or `password authentication failed`

**Check**:
```bash
# Verify Postgres is running
psql -U applaa_user -d applaa -c "SELECT 1;"

# Check backend .env
cat backend/.env
```

**Solution**: Ensure Postgres credentials match in `backend/.env`
